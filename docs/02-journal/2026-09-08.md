## Appris
- Faire la simulation d'une concetion pour avoir une idée sur comment ce serz dans la vie rélle
- Il faut paramétrer les même les mèches à utiliser dans la concetion
- L'épaisseur du matériau brut à friser doit être le même dans la conception que dans la vie réelle tandis qu'on doit laisser une marge pour la longueur et la largeur.
- IL y'a plusieus type de fabrication: additive, soustractive, découpe etc......
